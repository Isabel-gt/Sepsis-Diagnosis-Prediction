# Sepsis-Diagnosis-Prediction

## Overview of the Project
Application of data anlaysis and machine learning to design an end-to end machine learning pipeline for predicting binary outcomes from a real-world dataset.

<p align="justify">The analysis, the visualizations and the models were created using Python.</p>
